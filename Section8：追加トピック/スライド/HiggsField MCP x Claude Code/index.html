FIVE ELEMENTS

CAUTION

自分で試すときの注意点

  • 指示は5つの要素で組み立てる
    画像を2枚渡すなら「動き」と「カメラワーク」が中心
  • 作る前に、案を出してもらう
    「まだ作らないで、まず案を見せて」の一言。プランモードも同じ狙い
  • 枚数・区間の数・秒数は、自分で指定する
    任せきりにすると本数が増え、そのぶんクレジットを使う
  • 仕事で使うなら、権利のまわりを確認する
    どこまで使えるかはプランと利用条件による
まず軽く作って、確かめて、気になるところだけ直していく
