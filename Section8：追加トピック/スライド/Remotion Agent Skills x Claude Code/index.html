WHAT IS REMOTION

手で編集するのではなく、コードで組み立てる

ふつうの動画編集ソフト
タイムラインに素材を
手で並べていく
同じ作業をもう一度やるには
また手で並べ直す
→
Remotion
「今、何コマ目か」から
見た目をコードで計算する
コードだから
同じ作業を何回でも繰り返せる
テロップを乗せる・素材を重ねるといった編集は、Remotion でもできます
WHY REMOTION

AI動画ツールが他にもある中で
Remotion を選ぶ理由

01
同じ型の動画を
データ差し替えで作れる
型は同じ、中身は人それぞれ
Spotifyの「Wrapped」も
この作り方
02
試す段階では
お金がかからない
個人・3人以下の会社は無料
自分のパソコンで動かすので
生成ごとの課金がない
03
これまでの壁と
その越え方
コードで書く道具なので
React が書ける人の道具だった
→ そこを Claude Code が埋める
凝った動画を1本だけ作るなら、編集ソフトやAI動画ツールのほうが速いこともあります

SUBTITLE SOURCE

テロップの文面は、自分で書かなくていい

やり方1
Claude Code に
考えてもらう
その動画を Claude Code に
作らせたのなら、中身はすでに知っている
→ 文面も表示する秒数も任せられる
やり方2
文字起こしを使う
（音声のある動画）
文字起こしをテキストにすれば
一から書かずに済む
→ 変換ミスや区切りも直してもらえる
やり方2の注意
  • AIは音声を聞けません。人名や数字は直せないので、最後は自分で目を通す
  • 外部のサービスで文字起こしを取ると、音声の中身がそこに渡ります。社外に出せない内容が入っていないか先に確認する

CHECK

書き出した動画で、見るところは4つ

01
時間
書いた時間にテロップが出ているか
AIがコマ番号に直したところなので念のため
02
抜けと並び
全部出ているか、順番どおりか
03
読みやすさ
はみ出していないか、端に寄りすぎていないか
帯の濃さは見やすいか
04
元の動画
映像が切れていないか、縦横比が変わっていないか
音のある素材なら、音が残っているかも
テロップのリストを手元に置いて、見比べてください
SCALE

データを差し替えれば、
同じ型の動画を何本でも

手作業でやると
1本ずつ開いて
名前を打ち替えて作り直す
10人なら10回
100人なら100回
→
コードでやると
一覧データを渡して
まとめて書き出す
既存の動画へのテロップ入れも
一覧からの紹介動画も
仕組みは同じ
GMOの技術ブログでは、インタビュー動画30本以上へのテロップ挿入を夜間に無人で完了したと報告されています
CLOSING

手作業の繰り返しを、仕組みに置き換える

今回追加で覚えて帰ってほしい使い方
Claude Code に頼めば、コードが書けなくても
Remotion で動画が作れる
1本作るのも、テロップ入れも、量産の指示も、やったことは日本語で頼んだだけ
テロップ入れ・メンバー紹介・商品紹介・ランキング・データの可視化——
同じ作業を繰り返している場面ほど、置き換えたときの効果が出ます
CAUTION

自分で試すときの注意点

  • 書き出しには時間がかかる
    まずは尺を短く、解像度も控えめに。元素材が高画質だと処理が重くなる
  • 完全に無料ではない
    個人・3人以下の会社は無料。4人以上の営利企業で使うならライセンスが必要で、
    Claude Code に書かせる人もその対象に含まれます
  • 一発で思いどおりにならないこともある
    確かめて直す、を繰り返す。エラーはそのまま貼って相談できます
