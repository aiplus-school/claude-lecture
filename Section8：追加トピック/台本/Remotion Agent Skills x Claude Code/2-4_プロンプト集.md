# プロンプト集 — Remotion Agent Skills　日本語の指示だけで動画を作り、同じ型を量産する

動画内では、このプロンプト集の番号（P1〜P15）を指しながら進めます。コピーしてそのままお使いください。〔　〕は、ご自分の内容に置き換える場所です。

**上から順に使っていけば、準備から動画の書き出しまで一通り進みます。**（Node.js の入れ方だけは概要欄に載せています。P1 の前に済ませてください）

## P1. 準備を任せる（Remotion のインストール）

Remotion のインストールと下準備を、コマンドを打つ代わりに Claude Code にやってもらうプロンプトです。**Remotion 公式が案内しているプロンプトをもとにしています。**

**〔　〕の場所は必ずご自分で指定してください。** 指定しないと、Claude Code を起動しているフォルダの中に作られます。OneDrive や iCloud などの同期フォルダの外を指定してください。

```
Remotion を使えるように準備してください。順番にお願いします。

1. Remotion の Agent Skills を入れる
   npx -y skills@latest add remotion-dev/skills -g -y
2. そのスキルを使って、〔例：C:\dev〕の下に my-video という名前で
   Remotion のプロジェクトを作る（テンプレートは blank）
3. 動画の書き出しに使うブラウザを先に取ってくる
   npx remotion browser ensure

コマンドを実行する前に、それが何をするコマンドかを一言ずつ教えてください。
最後に、プレビュー（npm run dev）の開き方も教えてください。
```

> ⚠️ **実行し終わったら、Claude Code で `/reload-skills` を打ってください。** 入れたばかりのスキルは、読み直さないと使えるようになりません（`/` で始まるコマンドが出てきません）。

> ⚠️ **Node.js のインストール（概要欄の①②）は、この方法では行えません。** インストールの途中でパソコンの許可を求める画面が出て、そこは Claude Code からは操作できないためです。**公式のプロンプトも「Node.js が入っていること」を前提にしています。** Node.js だけは先にご自分で入れてください。

> 💡 コマンドの末尾に付いている `-y` は、「途中で聞かれても自動でOKと答える」という指定です。これがないと質問が出て、そこで止まってしまうことがあります。

## P3. 構成を相談する（まだ作らせない）

いきなり作らせると、思っていたものと違う動画が出てきて、直すところから始まることがあります。**先に「15秒をどう使うか」を言葉で出させて、そこで擦り合わせてから作らせる**ためのプロンプトです。やっていることは、動画の**台本を一緒に考えてもらう**のに近いです。

例として**サッカークラブの試合告知**を入れてあります。〔　〕を置き換えれば、他の題材でもそのまま使えます。

Claude Code のプランモードでも同じことができます。プランモードにすると、ファイルを書き換える前に「こう作ります」という計画を出して承認を待ってくれます。

```
〔例：地域のサッカークラブの試合告知〕のプロモーション動画を作りたいです。
15秒・縦型（1080×1920）、SNSに投稿するショート動画です。

写真・動画・音源といった素材は用意していません。
図形・グラデーション・文字だけで成立する構成にしてください。

まだコードは書かないでください。まず構成案を、次の条件で3案出してください。

【構成の条件】
- 15秒を3〜5個のカットに割る。1カットは2〜4秒
- 1カットに入れる文字は1〜2要素まで（詰め込むと縦型では読めないため）
- どのカットにも動きを入れる。止まったままの画面を作らない
- 最初の1秒で何の動画か分かるようにする（SNSでは冒頭で見るのをやめられるため）
- 最後のカットで〔例：日時・会場・クラブ名〕を出して締める
- 画面の上下左右10%には文字を置かない（スマホの表示で隠れるため）

【各案に書いてほしいこと】
- 秒の区切りごとに「画面に何が出るか」「何がどう動くか」「文字は何か」を表にする
- その案がどういう印象になるか（例：勢い重視／落ち着いた告知）を一言
- 素材なしでどう見栄えを作るか（図形・線・色の使い方）

あわせて、これを Remotion でどう作るか（幅・高さ・fps・全体のコマ数）も書いてください。
初心者にも分かるように、専門用語には短い注釈をつけてください。
```

**A案・B案…** のように複数の案が返ってきます。**どれで作るかを選んで、次の P4 で「B案でお願いします」と名前を出して伝えてください。** どの案も違うと感じたら、「もっと勢いのある案に」「最後の告知をもっと長く」のように日本語で注文をつけて、出し直してもらえます。

## P4. 動画を1本作らせる

**構成が決まっても、動きの質までは決まっていません。** ここで動かし方の注文をまとめて出しておくと、仕上がりが変わります。とくに**「一定の速さで動かさない」「背景も止めない」**の2つは、素人っぽさが出やすいところです。

```
〔選んだ案：例 B案〕でお願いします。その構成で、動画を1本作ってください。

動きは次を守ってください。
- 一定の速さで動かさない。動き出しと止まり際に緩急をつける
  （Remotion の spring や easing を使ってください）
- 文字は一度に全部出さず、単語ごと・行ごとに時間差で出す
- 背景も止めない（ゆっくり寄る、グラデーションの色がゆっくり変わる 等）
- カットの切り替えはフェードだけで済ませず、位置や大きさの変化も入れる
- 〔日付・スコア・背番号〕のような数字は、パッと出さずに動きをつけて出す
- 文字は縦型で読める大きさにする（見出しは画面の幅の8割を使うくらい）
- 使う色は3色までに絞る

まず Remotion Studio でプレビューできる状態にして、
開くためのアドレス（URL）も教えてください。
あとから Studio の画面上で直接編集できる形にしてください。
```

> 💡 **P3を使わず、ここから始めることもできます。** その場合は1行目を、作りたい内容の説明に差し替えてください。
> 例：`〔テーマ〕を伝える15秒・縦型（1080×1920）のショート動画を1本作ってください。素材は使わず、図形と文字だけで作ってください。`

> 💡 **最後の1行を入れておくと、文字の大きさや位置を、あとから Studio の画面上で直接直せる形**で作ってくれます。入れないと、画面から直せない書き方になることがあります。

## P5. プレビューを見て直す

プレビューは、**P4のあとに Claude Code が返してくる `http://localhost:3000` のようなアドレスを、ブラウザに貼れば開きます。** 数字の部分は環境によって変わることがあるので、返ってきたものをそのままコピーして使ってください。**開いたら、画面の左側で今回作ったものを名前で選びます**（前に作ったものも残っています）。

**アドレスが返ってこないときや、あとで開かなくなったときは、Claude Code に頼み直してください。**

```
プレビュー（Remotion Studio）を立ち上げ直して、
開くためのアドレス（URL）を教えてください。
```

直したいところがあれば、そのまま日本語で頼みます。

```
〔例：文字が小さいので大きく／出るのが早すぎるのでもう少しゆっくり〕に直してください。
```

## P8. すでにある動画にテロップを乗せる

### 使うファイルをダウンロードする

使うファイルは2つです。**元になる動画**（`source.mp4`）と、**テロップのリスト**（`subtitles.txt`）。**動画で使っているものと同じファイルを、こちらに置いてあります。**

📁 **[素材のダウンロード（Googleドライブ）](https://drive.google.com/drive/folders/1sygb72CEeWTAcBVNRngiWVdQLpI3N9fe?usp=sharing)**

**ご自分の動画とテキストで試していただいてもかまいません。** その場合は、下のプロンプトのファイル名をご自分のものに置き換えてください。

### 置き場所

ダウンロードした2つを**1つのフォルダにまとめて**、プロジェクトの `public` フォルダの中に置きます。

```
C:\dev\telop-demo-work\
├── public\
│   └── telop-demo\        ← この動画に使うものは、全部この中
│       ├── source.mp4
│       └── subtitles.txt
└── src\
    └── TelopDemo\         ← この動画のコードも、まとめて1つのフォルダに
```

**動画1本につき、素材のフォルダ1つ・コードのフォルダ1つ。** そして**両方に同じ名前をつけます**（ここでは `telop-demo` と `TelopDemo`）。プロジェクトの直下にファイルを直接置いてしまうと、2本目・3本目を作ったときに「どの素材がどの動画のものか」が分からなくなります。**最初の1本目からフォルダを分けておくのが、後で楽になるやり方です。**

> 💡 `public` は Remotion の決まった名前のフォルダです。Remotion は書き出すとき、内部でブラウザを使って画面を描いています。**そのブラウザから見える場所＝ `public` の中に置いたものだけ**が動画に読み込めます。だから素材はここに入れます。

> 💡 **`subtitles.txt` は「時間の行」と「文字の行」が交互に並んだテキストです。** ダウンロードして中を開いてみてください。**この形になっていれば、中身は何でもかまいません。**

### 実行するプロンプト

**動画を Claude Code に添付する必要はありません。** 添付しても中身を見てもらえるわけではなく、**フォルダに置いて、置き場所を伝える**のが確実です。テロップを乗せる作業は「動画の上に文字を重ねるコードを書く」ことなので、Claude Code に必要なのは**ファイルがどこにあるか**だけです。

```
上記で指定したフォルダ中の public/telop-demo フォルダに、
元になる動画 〔例：source.mp4〕 と、テロップのリスト subtitles.txt を置きました。

〔動画ファイル名 例：source.mp4〕 の上に、subtitles.txt の内容のとおりにテロップを乗せてください。
- 各テロップは、書いてある時間（0:03 など）に画面下に表示
- 数秒で次のテロップに切り替わるように
- テロップは読みやすいように半透明の帯＋白文字で
時間（タイムコード）からコマ番号への変換もお願いします。

新しく書くコードは src/TelopDemo という専用のフォルダにまとめて、
前に作った動画のコードと混ざらないようにしてください。
まずプレビューできる状態にしてください。
```

> 💡 **最後の2行が、2本目以降で効いてきます。** これを言わないと、前に作った動画のファイルに直接手を入れてしまい、**前の動画が壊れることがあります。** 「新しい動画は、新しいフォルダに」と毎回伝えるだけで防げます。

## P11. 同じ型で量産する

先に、一覧データを用意しておきます。中身はこの形です。**メンバー紹介・商品紹介・ランキング・物件情報など、1件ずつ中身が変わるものなら同じように使えます。**

```
名前 / 肩書き / ひとことコメント
佐藤ゆい / デザイナー / 手を動かすのが好きです
田中けん / エンジニア / コードで世界を作ります
…（あと数件）
```

```
このデータ一覧（〔ファイル名：例 members.txt〕）を読み込んで、
最初に作った動画と同じデザイン・同じ動きで、1件ずつの動画をまとめて書き出してください。
〔名前・肩書き・コメント〕の部分だけ、それぞれの内容に差し替えてください。
1本ずつ別ファイルとして、〔名前〕がファイル名に入るように書き出してください。
書き出し先は out/〔まとめの名前：例 members〕 という専用のフォルダにまとめてください。
```

本数を増やすほど書き出しに時間がかかり、動画ファイルでディスクも埋まります。まずは数本から試してください。

> 💡 **書き出し先も1つのフォルダにまとめます。** P8と同じ考え方です。何本も書き出すと、ほかの動画のファイルと混ざって「どれがどれか分からない」状態になりやすいので、**まとめ単位でフォルダを分けておきます。**
