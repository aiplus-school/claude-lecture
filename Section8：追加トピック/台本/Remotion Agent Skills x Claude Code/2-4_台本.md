## [P1] カバー — Remotion Agent Skills　日本語の指示だけで動画を作り、同じ型を量産する

今回は、Remotion（リモーション）と Claude Code を組み合わせて、**プログラムを1行も書かずに、日本語の指示だけで動画を作る方法**を学びます。

作るのは1本だけではありません。**すでにある動画にテロップを自動で乗せる**という、実務でよく出てくる作業もやります。そして最後には、**同じ型の動画を、データを差し替えて何本も作る**という使い方まで話を進めます。この「まとめて作る」使い方は、ほかのAI動画ツールでは扱いにくいことが多いところです。

Remotion は聞き慣れない名前だと思うので、まずは Remotion がどういう道具なのか、というところから始めましょう。

---

## [P2] Remotion とは — 手で編集するのではなく、コードで組み立てる

CapCut や Premiere のような動画編集ソフトは、タイムラインの上に素材を並べて、**手で**編集していきますよね。Remotion は、そのやり方が違います。**手で並べるのではなく、コードで動画を組み立てる道具**です。

もう少し正確に言うと、Remotion は React（リアクト）という、もともとはWebサイトを作るための技術を使って動画を作ります。専門用語がいくつか出てきますが、意味は概要欄にまとめてあるので、ここでは雰囲気だけつかんでください。

イメージとしては、Remotion が「今、動画の何コマ目か」という数字と、真っ白なキャンバスを渡してくれる。そこに「1コマ目はここに文字、10コマ目は少し右に移動」というふうにコードで描いていくと、それが動きになってアニメーションになる——そういう仕組みです。

実は、**動画にテロップを乗せる、素材を重ねるといった、編集ソフトでやることも Remotion でできます。** 今回の後半では、すでにある動画にテロップを乗せる作業を実際にやってみます。編集ソフトと違うのは、**その作業を「手で」やるか「コードで」やるか**だけです。そして**手ではなくコードでやるからこそ、同じ作業を何回でも繰り返せる**——ここは、後で量産の話としてもう一度出てきます。

## [P3] なぜ Remotion なのか — 同じ型の動画を、データを差し替えて作れる

ここで、なぜ Remotion なのかという話をします。AIで動画を作るツールは他にもあります。その中で、なぜ Remotion を使うのか。

正直にお伝えすると、**凝った動画を1本だけ作るなら、ふつうの編集ソフトやAI動画ツールのほうが速いこともあります。** Remotion が得意なのはそこではありません。

Remotion が得意なのは、**同じデザインで、中身だけ違う動画をたくさん作る**ときです。中身がコードでできているので、データを差し替えれば動画がそのぶん出てきます。手で1本ずつ作っていたら日が暮れる作業を、仕組みで片付けられる。**この「たくさん作る」ところは、手作業の編集ソフトでは難しいところです。**

たとえば、Spotifyが年末に配信している「Wrapped」。ユーザー一人ひとりの1年間の再生データをまとめた、あの個人別の動画です。あれはユーザーの人数分、自動で作られています。Remotion は、ああいう**「型は同じ、中身は人それぞれ」の動画**を作るために使われています。

もうひとつ、始めやすさもあります。**個人での利用や、3人以下の会社であれば無料で使えます。** 商用の動画に使っても料金はかかりません。AI動画ツールの多くは月額や生成ごとの課金がありますが、Remotion は自分のパソコンで動かすので、試す段階でお金がかからない。ここも選ぶ理由になります。（4人以上の会社で業務に使う場合は有料のライセンスが必要です。この条件は最後にもう一度お伝えします。）

ただし、Remotion には壁がありました。**コードで動画を書く道具なので、本来は React が書ける人しか使えなかった**んです。動画を作りたい人と、React が書ける人って、たいてい別の人ですよね。**これが、Remotion を使ってみたい人の前に立っていた壁でした。**

その壁を越えるために使うのが、Claude Code です。実際にやってみましょう。

なぜこれが要るかというと、Remotion には「React を知っている人ほどハマる」書き方の癖がいくつかあるからです。ふつうの React なら使える機能が、Remotion では使えなかったりする。人が引っかかりやすいこういうところを、この資料を読んだAIは避けて書いてくれるようになります。公開されている統計では、世界で4番目に多くインストールされているスキルだそうです。

ひとつ補足しておきます。n8n の回では **MCP** という、AIを外部のサービスに直接つなぐための仕組みを使いました。**今回は MCP ではありません。** MCP が「AIに外のサービスを操作させる仕組み」なのに対して、Agent Skills は「AIに書き方のルールを渡す仕組み」です。今回AIにやってほしいのは、外のサービスにつなぐことではなく、正しいコードを書くことだけ。だから MCP ではなく Agent Skills を使っています。

### まず、構成から相談する

では、動画を作ってもらいます。**今回作るのは、地域のサッカークラブの試合告知**という想定です。15秒の縦型、SNSに投稿するショート動画ですね。

ただ、いきなり「作って」とは頼みません。**先に構成を相談します。ここで使うのは、プロンプト集のP3です。**

なぜ先に相談するかというと、**「かっこいい動画を作って」だけで頼むと、たいてい平凡なものが返ってくる**からです。背景に文字が1つ出て終わり、というような。AIは、こちらが言わなかったところを無難な方向に埋めるので、**注文が大ざっぱだと、出てくるものも大ざっぱになります。**

なのでP3では、**15秒を3〜5カットに割る、1カットは2〜4秒、どのカットにも動きを入れる、最後は日時と会場で締める**——といった条件をこちらから出しています。**写真や動画の素材は使わず、図形と文字だけで作る**という条件も入れてあります。素材を集めるところで止まってほしくないからです。

（P3を貼り付けて実行。構成案が3つ出てくるのを見せる）

（返ってきた案を上から順に見せながら）このように、**秒の区切りごとに「何が出て、何がどう動くか」が表になって**返ってきます。3案あって、それぞれ印象が違います。

ここで**自分の目で選びます。** ここは人が決めるところです。今回は〔B案〕でいきましょう。

**Claude Code のプランモードを使うのも同じ狙いで使えます。** プランモードにしておくと、AIはファイルを書き換える前に「こう作ります」という計画を出して、こちらの承認を待ってくれます。意図とずれたまま作り進められるのを防げます。

**続けて、プロンプト集のP4です。** 冒頭で「**B案でお願いします**」と、**どの案なのかを名前で伝えている**のがポイントです。これを言わないと、AIがどれで作るか決めきれず、聞き返してきたり、勝手に選んだりします。

そしてP4には、**動かし方の注文**をまとめて書いてあります。一定の速さで動かさない、文字は一度に全部出さない、背景も止めない——**このあたりを言うか言わないかで、仕上がりが変わります。** 逆に言えば、**動画として見栄えする条件を、こちらが言葉で持っておく必要がある**ということです。

コードができました。**中身を細かく読む必要はありませんが、2か所だけ見ておきます。頼んだとおりの構成になっているか**です。

（`Main.tsx` を画面に映し、カットが並んでいるところまでスクロールしてから話し始める）

その2行下の数字が、**何コマ目から始まって、何コマ分続くか**です。durationInFramesの行です。カット1は0コマ目から90コマ分。この動画は1秒あたり30コマなので、**90コマは3.0秒**。カット2は90コマ目から120コマ分なので4.0秒です。

### すでにある動画にテロップを乗せる

**すでにある動画に、テロップを自動で乗せてみます。** 動画編集をやったことがある方なら分かると思いますが、テロップ入れは**地味で時間のかかる作業**ですよね。1本の動画に手で何十個も置いて、タイミングを合わせて……。ここをコードで片付けます。

準備として、テロップの中身をテキストファイルで用意します。**用意のしかたは、大きく2つあります。**

## [P5] テロップの用意 — 自分で書かずに済ませる2つのやり方

（画面収録からスライドに切り替えて説明する）

**ひとつは、Claude Code に考えてもらうやり方です。** さきほどのように、その動画自体を Claude Code に作らせたのであれば、**中身はすでに知っている**わけですよね。であれば「どこに、何のテロップを入れるか」も任せられます。表示する秒数まで考えてくれます。**テキストを自分で書く必要がありません。**

**もうひとつは、音声のある動画で、文字起こしを使うやり方です。** 動画から文字起こしを取って、それをテキストファイルにすれば、テロップを一から書かずに済みます。文字起こしには変換の間違いが混ざりますが、**そこも Claude Code に直してもらえます。** 文の途中で切れて読みにくいところも、テロップ向けの区切りに整えてもらえます。

（スライド右下の注意書きを指しながら）ただし2つ注意があります。**AIは音声を聞けません。** 直せるのは、文脈からおかしいと分かる言葉だけです。**人名や数字は直せないので、最後はご自分で目を通してください。** それから、**文字起こしを外部のサービスで取る場合は、音声の中身がそこに渡ります。** 社外に出せない内容が入っていないか、先に確認してください。

**今回は、すでに用意してあるテキストファイルと動画を使って進めます。** ここで使う動画とテキストは、**概要欄からダウンロードできる**ようにしてあります。

このファイルは、**元になる動画といっしょに、1つのフォルダにまとめて**置いておきます。

## [P8] 量産 — データを差し替えれば、同じ型の動画を何本でも

いまやったのは、1本の動画へのテロップ入れでした。**Remotion が向いているのは、これを何本分もまとめてやるところです。**

方向は2つあります。ひとつは、**いまのテロップ入れを、何十本もの動画にまとめて適用する**こと。もうひとつは、**名簿のような一覧データから、1件ずつ動画を作る**こと。どちらも、やっていることは「データを差し替えて、同じ処理を繰り返すだけ」で、仕組みはまったく同じです。

**ここは題材を選びません。** メンバー紹介、商品紹介、ランキング、物件情報——**1件ずつ中身が変わるもの**なら、同じやり方が使えます。

頼み方も、これまでと変わりません。**プロンプト集のP11が量産用です。** 一覧データのファイル名を伝えて、**最初に作った動画と同じデザイン・同じ動きで**件数分まとめて書き出してほしい、と頼む内容になっています。**さっきP3とP4で決めた構成と動きが、そのまま型として使い回される**ということですね。

（プロンプト集のP11を画面に表示する。データの形もP11の中に例として載っているので、別のファイルは開かない。※ここは実行しない）

ここでの実行は、今回は割愛します。頼み方はいま見ていただいたとおりで、あとはデータの行数が増えるだけです。まとめて作ると動画ファイルでパソコンの容量を使うので、ご自分で試すときは数本から始めてみてください。

こう頼むと Claude Code は、「データを1件ずつ読んで、同じデザインに当てはめて、動画にする」という**繰り返しの処理**を書いてくれます。これを手作業でやるなら、編集ソフトで1本ずつ名前を打ち替えて作り直すことになります。10人いれば10回、100人いれば100回。それが、データを差し替えるだけで済む。**ここがコードで動画を作る利点です。**

実際の例もあります。GMOという会社の技術ブログによると、この方式でインタビュー動画30本以上にテロップとスコア表示をまとめて挿入し、**夜間にパソコンへ任せておくだけで、約15時間かけて無人で完了した**そうです。人が張り付く必要がない。仕組みとしては、5本でも30本でも100本でも同じです。

## [P9] クロージング — 手作業の繰り返しを、仕組みに置き換える

今回は、Remotion と Claude Code を組み合わせて、コードを書かずに動画を作り、テロップを自動で乗せ、同じ型を何本でも作れるところまで見てきました。

今回追加で覚えて帰っていただきたいのは、**Claude Code に頼めば、コードが書けなくても Remotion で動画が作れる**ということです。1本作るところも、テロップ入れも、量産の指示も、やったことは日本語で頼んだだけでした。これまで「プログラミングができる人の道具」だったものが、Claude Code を挟むことで、みなさんの手元でも使える道具になります。

そして、**いま手作業でやっている動画まわりの作業を、この組み合わせで仕組みに置き換えられないか**、という目でご自分の仕事を見直してみてください。テロップ入れ、メンバー紹介、商品紹介、ランキング、データの可視化——同じ作業を何度も繰り返している場面ほど、置き換えたときの効果が出ます。

## [P10] 最後に — 自分で試すときの注意点

最後に、自分で試すときに知っておいてほしいことを3つお伝えします。

1つ目。**書き出しには時間がかかります。** 動画の書き出しはパソコンの力をかなり使う処理です。まず試すときは、尺を短く、解像度も控えめにしてください。とくにテロップ入れは元の動画を読み込むぶん重くなります。4Kのような高画質の素材だと、途中の処理でディスクを数ギガバイト使うという報告もあるので、**元素材は短く、画質も控えめに**して始めるのが安全です。

2つ目。**Remotion は完全に無料ではありません。** 個人、または3人以下の会社であれば無料で、商用利用もできます。学習で試す分にはお金はかかりません。ただし、**4人以上の営利企業で業務に使う場合は有料のライセンスが必要**です。しかも公式の条件では、**Claude Code のようなツールに書かせる人もその対象に含まれます。**「自分はコードを書いていないから対象外」とはならないので、会社で使う前に必ず確認してください。条件と公式ページのリンクは概要欄に載せています。

3つ目。**一発で思いどおりにならないこともあります。** 指示の出し方を変えたり、デザインの注文を足したり、設定を調整したり——**実際に自分で回しながら、少しずつ直していくもの**だと考えてください。エラーが出たときは、その文章をそのまま Claude Code に貼って相談できます。プロンプト集のP7とP15がその用途です。

今回のデモをそのまま真似して終わりにせず、**まずご自分のデータで1本作ってみて、そこから育てていってください。**
