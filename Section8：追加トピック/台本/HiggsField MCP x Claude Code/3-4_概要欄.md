# 概要欄 — Higgsfield MCP　Claude Codeから動画を生成しよう

この動画では、Higgsfield を Claude Code につないで、**5枚の画像を4つの区間でつなぎ、手直しして、1本の動画に仕上げる**までを会話だけで進める方法を紹介しています。

動画で使ったプロンプトは、**別ファイル「プロンプト集」**にまとめて配布しています。そちらをコピーしてお使いください。

---

## 📌 この動画の前提

- **Higgsfield のアカウントを持っていること。** Higgsfield 自体の基本的な使い方は基礎講座で解説しています。
- **Higgsfield の有料プランに加入していること。ただし、いちばん安いプランでは足りません。**
  - 無料で使える範囲では、**この動画で使う動画モデルが対象外**です。
  - **いちばん安い有料プランも、使えるモデルが限定されていて対象外**です。**この動画で使う「画像と画像の間をつなぐ」機能も使えません。**
  - 👉 **料金ページで「すべてのモデルと機能が使える（Access to all models & features）」と書かれている段**を選んでください。**プラン名は `Plus` と表示されることも `Pro` と表示されることもあります。迷ったら、このどちらかを選んでください。**
- **Claude Code が使えること。**（インストール・ログイン済み）

> ⚠️ **プラン名・内容・金額は変更されることがあります。また、アクセスするタイミングによって、表示されるプラン名や金額が違う場合があります。**
> プラン名を1つに絞れないのはそのためです。**「すべてのモデルと機能が使える」と書かれているかどうか**で判断してください。最新の情報は必ず公式の料金ページでご確認ください。

## 🎬 4本の動画をつなぐには（ffmpeg が必要です）

動画をつなぐ作業は Higgsfield ではなく、**お使いのパソコンの中で行われます。** そのため **ffmpeg（エフエフエムペグ）** という、動画をあつかうための道具が必要です。

- **すでに入っている場合**：そのままプロンプト集のP6が使えます。
- **入っていない場合**：Claude Code に「ffmpeg を入れたい」と伝えると、お使いのパソコンに合わせた入れ方を案内してくれます。

> ⚠️ **入れるときの注意。** インストールの途中で、**パソコンから「変更を許可しますか」といった確認画面が出ることがあります。** これは Claude Code が代わりに押すことはできません。**内容をご自身で確認したうえで、許可するかどうかを判断してください。** 会社から貸与されたパソコンなど、ソフトを自由に入れられない環境では、管理者にご相談ください。
>
> 手動で入れる場合は、公式サイトからも入手できます → https://ffmpeg.org/download.html

## 🔌 Higgsfield MCP を Claude Code につなぐ手順

> ⚠️ **コネクタの一覧を探しても、Higgsfield は出てきません。** n8n の回では一覧から名前で選べましたが、Higgsfield は一覧に登録されていないため、**接続先のURLを自分で入れて登録**します。探しても見つからず手が止まりやすいところなので、先にお伝えしておきます。

> ⚠️ **公式サイトで「Claude Code」のタブを開くと、別の方法が出てきます。** そちらは **CLI とスキルを使う方法**で、本講座で扱う MCP とは別のものです。**MCPでつなぐ方法は「Claude」のタブに載っています。** 下の手順はそちらに沿っています。

### ① 接続用のURLをコピーする

Higgsfield にログインし、上のメニューの **「MCP & CLI」**（ https://higgsfield.ai/mcp ）を開きます。**「Claude」のタブ**が選ばれた画面になるので、①に出ているURLをコピーします。

```
https://mcp.higgsfield.ai/mcp
```

上のURLをそのままお使いいただいても構いません。

### ② コネクタとして登録する

同じ画面の **「Open Claude Customize」** を押すと、**「カスタムコネクタを追加」** の画面が開きます。（Claude の設定から開く場合は **設定 → コネクタ → 「追加」→「カスタムコネクタを追加」**）

1. **「名前」** に `Higgsfield` と入力する
2. **「リモートMCPサーバーURL」** に、①のURLを貼り付ける
3. **「追加」** を押す

**「詳細設定」** の中に **OAuth Client ID** と **OAuthクライアントシークレット** の欄がありますが、**どちらも「任意」なので空のままで大丈夫です。**

入れるのは**接続先の住所だけ**です。**APIキーの発行も、設定ファイルの編集も要りません。**

> 💡 画面に「**信頼できる開発者のコネクタのみをご使用ください**」という注意が出ます。上のURLは **Higgsfield が公式サイトで配布しているもの**です。

### ③ サインインして許可する

登録しただけでは、まだご自分の Higgsfield のアカウントとはつながっていません。画面にも「**Higgsfield さんにまだ接続されていません**」と出ます。

1. **「連携/連携させる」** を押す
2. Higgsfield のアカウントで**ログイン**する
3. 「Claude が Higgsfield を使ってよいか」を確認する画面で **「Allow」** を押す

Claude に渡るのは、**本人確認・メールアドレス・ログイン状態を覚えておくこと**の3つです。

### ④ 「ツールの権限」はそのままで大丈夫です

許可すると Higgsfield のコネクタの画面に戻ります。ここに **「ツールの権限」** という欄があり、**Claude が Higgsfield のどの機能をいつ使えるか**を設定できます。

はじめは **「承認が必要」**（使う前に一度確認する）になっています。**動画では、この設定のまま進めています。**

> ⚠️ **まとめて「許可」にするのはお勧めしません。** ここに並ぶツールには、動画や画像を作るもののほかに、**SNSへの投稿・サイトの公開・契約の自動更新の解除**にあたるものも含まれています。まとめて許可にすると、それらも確認なしで実行できる状態になります。
>
> 確認が煩わしい場合は、**ツールごとに個別で許可**できます（各ツールの行で切り替えます）。動画の生成に使うものだけを許可にしておくと、確認の回数を減らしつつ、他は止められます。

### ⑤ Claude Code から見えているか確認する

> 💡 **先に Claude Code を開き直してください。** つないだ内容は**セッションを始めるときに読み込まれる**ので、開いたままだと反映されません。

開き直したら **`/mcp`** と打ちます。一覧に `higgsfield` が**接続済み**で表示されていれば成功です。あわせて、Claude Code に「Higgsfield MCP で使えるツールを一覧してください」と聞いて、ツールが出てくれば確実です（プロンプト集のP1）。

### 別のつなぎ方（ターミナルから登録する）

コネクタの画面を使わず、ターミナルから登録することもできます。**結果は同じです。** どちらか一方だけを行ってください（**両方やると二重登録になり、片方で許可してももう片方に引き継がれません**）。

```bash
claude mcp add --transport http --scope user higgsfield https://mcp.higgsfield.ai/mcp
```

`--scope user` はどのプロジェクトからでも使えるようにする指定です。**この指定があるので、どのフォルダで実行しても結果は同じです。**

登録したあと、**Claude Code を開き直して `/mcp`** と打ち、一覧から **`higgsfield` を選んで `Authenticate`（認証）を選ぶ**とブラウザが開きます。**`/mcp` と打っただけではブラウザは開きません。** ここでログインして許可すると、表示が「認証が必要」から「接続済み」に変わります。

> 💡 うまくいかないときは、ターミナルで `claude mcp list` を実行すると、登録されているMCPと接続状態を一覧で確認できます。

## 📖 用語のかんたん解説

| 用語 | ざっくり言うと |
|---|---|
| **MCP** | AIを外部のツールとつなぐための共通規格。今回はこれで Claude と Higgsfield をつなぐ |
| **APIキー** | サービス同士をつなぐときに使う、パスワードのような文字列。**本来 Veo や Seedance のようなモデルを使うにはモデルごとに必要ですが、Higgsfield がまとめて引き受けているため、ご自分で用意する必要はありません** |
| **Veo / Seedance** | 動画を生成するAIのモデルの名前。Higgsfield では30種類以上から選んで使えます |
| **コネクタ** | Claude に外部サービスをつなぐ設定のこと。Higgsfield は一覧に無いので、URLを直接登録します |
| **プランモード** | Claude Code の機能。実行する前に「こう作ります」という計画を出して、承認を待ってくれる |
| **ターミナル** | パソコンに文字でコマンドを打って指示する画面。Windowsなら PowerShell／コマンドプロンプト、Macなら「ターミナル」。**本編の手順では使いません**（「別のつなぎ方」でのみ登場します） |
| **`--transport http`** | MCPサーバーへの接続方式の指定（「別のつなぎ方」で使います）。コマンドはそのままコピーで大丈夫です |
| **720p** | 動画の解像度のひとつ。数字が大きいほど画がきめ細かくなり、そのぶんクレジットを多く使います |
| **クレジット** | 生成のたびに減る、プランごとの残数。動画は1本ごとに消費します |
| **Kling 3.0** | 今回使う動画生成モデルの名前。**モデルは入れ替わることがあります** |
| **区間** | この動画での呼び方。となり合う2枚の画像の「間」を動画にしたもの。5枚なら4区間 |
| **ffmpeg** | 動画をつないだり変換したりする道具。4本を1本にまとめるときに使います |
| **登場人物の登録（Elements）** | 出したい人物や商品の画像を1枚登録しておく仕組み。**同じ人・同じ物を繰り返し出せるようになります**（プロンプト集のP5）。写真を何枚も集めたり、学習を待ったりする必要はありません |
| **縦型** | スマホ向けの縦長サイズ（9:16）。ショート動画でよく使われます |
| **非同期** | 指示を投げてから、出来上がるまで待つ仕組み。動画生成は時間がかかります |
| **GPT Image 2 / Nano Banana** | 画像を生成するAIモデル。今回は動画の素材づくりに使用 |

## 🎬 動画プロンプトの5要素

動画の指示は、次の5つを意識すると狙いに近づきやすくなります。

| 要素 | 内容 | 例 |
|---|---|---|
| ① 被写体 | 何を映すか | カウンターとカップ |
| ② 動き | 何がどう動くか | 湯気が立ちのぼる |
| ③ カメラワーク | カメラの動き | ゆっくり前に進む |
| ④ 雰囲気 | 明るさ・時間帯・トーン | 朝の柔らかい光 |
| ⑤ 尺とモデル | 何秒か・どの設定か | 5秒・縦型・720p・Kling 3.0 |

**今回のように画像を2枚渡す場合、①被写体と④雰囲気は、渡す画像がほぼ決めてくれます。** ですから、言葉で埋めるのは**②動きと③カメラワーク**が中心になります。**この2つが抜けると、2枚が入れ替わるだけの、止まったような画になりがちです。**

動かし方が思いつかないときは、**プロンプト集のP9**が使えます。2枚の画像を渡して、この5要素に当てはめた案を出してもらう内容です。題材は問いません。

> 💡 **①被写体に「特定の人」や「自分の商品」を出したいときは、画像を1枚登録しておけます。** 何も登録しないと、生成のたびに顔や服装が変わります。やり方はプロンプト集のP5です。

## 🔊 音について

**動画には、こちらが何も言わなくても音が付きます。** 動画の生成に含まれているので、**音のために追加でクレジットを使うことはありません。**

入れたい音のイメージがあるときは、生成をお願いするときに一文添えてください（プロンプト集のP3の2行目）。

> ⚠️ **区間ごとに別々に生成しているので、音も区間ごとに別々に付きます。** つないだあとに聴くと、**変わり目で音が切り替わる**ことがあります。気になる区間があれば、そこだけ作り直してください（P4）。

## ⚠️ 試すときの注意点

- **指示は5要素で組み立てる。** 画像を2枚渡す場合は、とくに「動き」と「カメラワーク」を必ず入れてください。
- **作る前に案を出してもらう。** 「まだ作らないで、まず案を見せて」と伝えるだけで、やり直しが減ります。生成には時間がかかるので、文字のやりとりで方向性を合わせておくほうが結果的に早いです。**何本かまとめて作るときほど効きます。**
- **区間の数・秒数は自分で指定する。** 「いい感じに」と任せきりにすると、**思っていたより本数が増えて、そのぶんクレジットを使ってしまう**ことがあります。まずは区間を少なく、秒数も短くして通してみてください。**モデルも指定してください。** 指定しないとAIが選び、**同じ5秒でも減るクレジットが変わります。**
- **直したい区間は、番号で伝える。** 「区間2だけ直して」のように指定しないと、すべて作り直しになることがあります。
- **直すときは、その区間を作り直す（P4）。** 作り直すと、直したいところ以外も変わることがあります。**作り直しにもクレジットを使います。**
- **同じ人や同じ商品を繰り返し出したいときは、画像を1枚登録する（P5）。** 登録しないと、生成のたびに顔や服装が変わります。**登録そのものにクレジットはかかりませんが、そのあとの生成には使います。**
- **動画は「投げて待つ」もの。** すぐには返ってきません。**できあがると、画面上で動画も確認できます。** 保存先も一緒に返ってくるので、あとから開き直すこともできます。
- **仕事で使う場合は、権利まわりを確認する。** 生成物をどこまで使えるかはプランと利用条件によります。公式サイトでご確認ください。
- **一回で思い通りにはなりません。** 「まず軽く作って、会話で少しずつ近づけていく」——この使い方だとラクに進められます。
