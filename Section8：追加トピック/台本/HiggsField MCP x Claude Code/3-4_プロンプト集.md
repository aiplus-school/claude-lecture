# プロンプト集 — Higgsfield MCP　Claude Codeから動画を生成しよう

動画内では、このプロンプト集の番号（P1〜P9）を指しながら進めます。**上から順に使える並び**になっているので、コピーしてそのままお使いください。〔　〕は、ご自分の内容に置き換える場所です。

Higgsfield を Claude Code につなぐ手順と、動画の素材に使う画像のダウンロードは、概要欄に載せています。

## P1. 接続確認

```
Higgsfield MCP で使えるツールを一覧してください。
動画生成では、どんなモデル・解像度・尺（秒数）を指定できますか。
また、始まりの画像と終わりの画像を指定して、その間をつなぐ動画は作れますか。
```

ツールの一覧が返ってくれば、つながっています。何も出てこない場合は、概要欄の手順で接続からやり直してください。**MCPを追加した直後は、セッションを開き直す**と認識されることがあります。

## P2. 区間ごとの構成を相談する（まだ生成させない）

Claude Code の**プランモード**でも同じことができます。プランモードにすると、実行する前に「こう作ります」という計画を出して承認を待ってくれます。

```
素材画像のフォルダに、場面の始まりとなる画像を5枚、順番に用意しています。
〔01_看板.png / 02_カウンター.png / 03_抽出.png / 04_ドリンク.png / 05_客席.png〕

となり合う2枚を「始まりの画像」と「終わりの画像」として、その間をつなぐ動画を4区間ぶん作り、
最後に1本につなげたいです。全体のイメージは「〔朝のカフェで、1杯のコーヒーが出てくるまで〕」。

まだ生成しないでください。まず、区間ごとに次を提案してください。
- どの画像からどの画像へつなぐか
- その区間で「何がどう動くか（動き）」と「カメラをどう動かすか（カメラワーク）」
- 4区間が場面の流れとしてつながっているか

条件：1区間は5秒、合計4区間で20秒。解像度は軽めの 720p を想定しています。

あわせて、残りのクレジットを確認して、この条件で足りるかを見てください。
足りなければ、何区間・1区間何秒までなら作れるか、配分の案も出してください。
```

**条件を数で書いているのには理由があります。** 「いい感じに」とだけ頼むと、区間の数や秒数をAIが無難に埋めてしまい、**思っていたより本数が増えることがある**ためです。〔　〕を差し替えれば、**他の題材でも同じように使えます。**

**残りのクレジットを聞いているのも、同じ理由です。** Claude Code は残高を読めるので、**足りるかどうかの判断ごと任せられます。** 自分で残高を見て割り算しなくても、「この予算ならこの配分」まで返ってきます。

## P3. 4つの区間をまとめて生成する

P2で返ってきた案をそのまま使うので、**P2の直後に貼ってください。**

```
その案でいきましょう。区間1から順に、各5秒・縦型・720p・Kling 3.0 で生成してください。
音は、それぞれの場面に合うものを入れてください。〔区間3は、抽出の音を強めに〕
生成が終わったら、それぞれの動画をプロジェクトの videos/ フォルダに、
区間の順番が分かる名前で保存して、保存先を教えてください。
```

案が複数返ってきたときは、冒頭を「〔1つ目の案〕でいきましょう。」のように、**どれなのか分かる形で指定**してください。

> ⚠️ **モデル名（Kling 3.0）は変わることがあります。** Higgsfield で使えるモデルは入れ替わるので、**そのまま貼って通らないときは、モデル名を外すか、いま使えるものに置き換えてください。**
> **それでもモデルは指定することをおすすめします。** 指定しないとAIが別のモデルを選び、**同じ5秒でも減るクレジットが変わる**ためです。

**音は、何も書かなくてもモデルが自動で付きます。** 動画の生成に含まれているので、**音のために追加でクレジットを使うことはありません。** 上の2行目は、入れたい音のイメージがあるときだけ書いてください。

## P4. 気になる区間だけ手直しする

```
〔区間2〕だけ直したいです。〔もう少しカメラの動きをゆっくり／終わりを明るく／湯気を強めに〕してください。
今の指示を土台に、そこだけ変えてもう一度作って、同じ名前で置き換えてください。
```

**どの区間かを必ず伝えてください。** 伝えないと、4本すべて作り直しになることがあります。

## P5. 登場人物を決めて、動画に出す

**人を出すと、生成のたびに顔や服装が変わります。** 同じ人を繰り返し出したいときは、**画像を1枚登録しておきます。**

```
〔人物画像のファイル名〕を、登場人物として登録してください。

そのうえで〔区間2〕を、この人が出てくる場面に作り直してください。
始まりと終わりの画像はそのままで、5秒・縦型・Kling 3.0 です。

動きは次のとおりにしてください。
・〔この人が、カウンターの内側からカップを置く〕
・置く場所は、〔終わりの画像でカップがある場所〕に合わせる
・一度置いたら、〔カップ〕はそこから動かさない
・置いたあと、この人は手を引いて画面の外に出る
・出てくるのは〔この人〕だけ。ほかの人は出さない
・カットは割らず、ひと続きで撮ったようにする

できたら別の名前で保存して、元の〔区間2〕も残しておいてください。
```

**登録は待ち時間なしで終わります。** 同じ人の写真を何枚も集めたり、学習が終わるのを待ったりする必要はありません。**登録すると番号が振られますが、こちらで打つ必要はありません。**「登録した〔バリスタ〕で」と伝えれば、Claude Code が当てはめてくれます。

**始まりと終わりの画像は、そのまま指定できます。** 構図はこれまでどおり2枚の画像で決めながら、そこに人だけを足す形になります。

### 動きを細かく書いているのには理由があります

**AIは、書かれていないところを無難な方向に埋めます。** 「カップを置く」とだけ伝えると、**置いたあとどうなるかが決まっていないので、勝手に動き出すことがあります。** 実際に、**置いたカップがひとりでに客のほうへ滑っていく**動画ができました。

上の6行のうち、とくに効くのが**置く場所の指定**です。**終わりの画像に写っているものは、最後にその位置になければなりません。** 違う場所に置かせると、**そこへ移動させて辻褄を合わせようとします。** これが「勝手に動く」の正体です。

**「〜しない」も書いてください。** 「動かさない」「ほかの人は出さない」「カットは割らない」は、書かなければ伝わりません。**やってほしくないことほど、言葉にする必要があります。**

**元の動画も残してもらいます。** 人がいない方といる方を見比べて、**どちらの作り方で進めるかを選べる**ようにするためです。

〔　〕を差し替えれば、**人物にかぎらず、自分の商品やペットなど、繰り返し出したいものに同じように使えます。** そのときも、**「置いたあと・出たあとどうなるか」まで書く**のを忘れないでください。

## P6. 4本を1本につなぐ

```
videos/ にある動画を、区間の順番どおりにつないで1本にしてください。
〔区間2〕は〔人物が入っている方〕を使ってください。
つなぎ目は前後を0.5秒ずつ重ねて、なめらかに切り替わるようにしてください。音も同じように重ねてください。
つないだものは videos/ に分かりやすい名前で保存して、保存先と合計の長さを教えてください。
```

**どちらを使うかを書き添えてください。** P5で区間2が2本になっているので、書かないと**どちらでつながれるか分かりません。** P5を使わなかった場合は、この2行目は消してかまいません。

**つなぎ目を重ねているのにも理由があります。** 区間は1本ずつ別々に作られるので、**どれも止まった画で終わり、止まった画から始まります。** そのままつなぐと、**変わり目で一度止まって見えます。** 少し重ねておくと、そこが目立ちません。

**重ねたぶん、全体は短くなります。** つなぎ目1つにつき0.5秒です。4区間なら**つなぎ目は3つ**なので、合計で1.5秒ぶん短くなります。

**動画をつなぐには、パソコンに ffmpeg（エフエフエムペグ）という道具が必要です。** 入っていない場合は Claude Code が入れ方を案内してくれます。詳しくは概要欄をご覧ください。

## P7. つないだ動画を紹介ページに埋め込む

**動画では実演していません。** 「作っているものに動画を差し込む」を自分で試したいとき用のプロンプトです。

```
いま作った、つないだ動画を使って、〔Rebel Coffee〕の紹介ページ（HTML1枚）を作ってください。
動画をトップに埋め込み、images/ に用意してある画像も適宜使ってください。
できたらブラウザで開いて確認できる状態にしてください。
```

〔　〕を差し替えれば、**商品紹介・お店の紹介・イベント告知など、他の題材でも同じように使えます。**

## P8. 生成に失敗した・待たされたとき（汎用）

```
生成が〔失敗した／いつまでも終わらない／イメージと違う〕状態です。
原因の見立てと、プロンプトや設定の直し方を教えてください。
別のモデルや設定に切り替えたほうがよければ提案してください。
```

## P9. 手持ちの画像で、何をどう動かせるか相談する（応用）

動かし方が思いつかないときに使うプロンプトです。**題材は問いません。**

```
〔画像のファイル名〕と〔画像のファイル名〕の2枚を、始まりと終わりにして
5秒の動画を作りたいです。
この2枚の間で動かせそうなものを、5要素（①被写体 ②動き ③カメラワーク ④雰囲気 ⑤尺・モデル）に
当てはめて3案出してください。まだ生成はしないでください。
それぞれ、どんな印象の動画になるかも一言添えてください。
```

気に入った案が決まったら、**P3の冒頭を「〔2つ目の案〕でいきましょう。」に書き換えて**続けてください。

---

### 自分の素材で試すときは

P2 の 〔　〕 をご自分の画像のファイル名と、作りたい動画の内容に置き換えてください。**画像の枚数を変えると、区間の数も変わります**（画像が3枚なら2区間、5枚なら4区間）。あわせて条件の「4区間で20秒」も書き換えてください。

**5要素（被写体・動き・カメラワーク・雰囲気・尺/モデル）のうち、画像を2枚渡す場合は「動き」と「カメラワーク」が中心になります。** 被写体と雰囲気は、渡す画像がほぼ決めてくれるためです。
